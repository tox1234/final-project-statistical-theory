# final-project-statistical-theory

This repository contains the full statistical analysis and codebase for the final project in the "Statistical Theory" course. The project investigates the complex statistical relationships between demographic factors, meteorological conditions, and air quality using a multidimensional dataset of 5,000 observations.

# How to run

1. clone the repository:
open cmd and type git clone https://github.com/tox1234/final-project-statistical-theory.git

2. enter the file:
type cd final-project-statistical-theory

3. install requirements:
now type pip install -r requirements.txt

4. finally run the main script!
type python main.py

tests will be printed on the terminal and the pictures will be saved on the folder.
